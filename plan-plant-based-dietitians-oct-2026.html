01

What we found

I loaded your contact page and thank-you page and read the published GTM container. PageView reaches Meta normally. The problem is where CompleteRegistration lands and what triggers it, made worse by the health category data-sharing restriction.

Two pixels, and the registration only reaches one of them

High impact

The Meta for WordPress plugin loads pixel 461876474856948 with its Conversions API connection. GTM loads a second pixel, 721212755566944. On /thank-you/ this is what Meta receives:

Event on /thank-you/Pixel 461876474856948 (WordPress plugin)Pixel 721212755566944 (GTM)
PageViewReceivedReceived
CompleteRegistrationNot receivedReceived

If your ad account and Events Manager view use the plugin pixel, Meta never sees a registration, even though the event is firing.

Triggers point at pages and forms that no longer exist

High impact

The container still holds triggers built for an older version of the site. Three of them no longer match anything live:

GTM settingWhat it expectsWhat the site does now
CompleteRegistration custom HTML tagURL contains /confirmation-pageThat page returns a 404
GA4 form submission triggerForm ID gform_9Live booking form is gform_3
Gravity Forms listenerAJAX confirmation eventForm submits by postback, then redirects to booking

The booking itself finishes inside Practice Better, so the registration only counts if Practice Better sends people back to /thank-you/ afterwards. That redirect needs checking on the call.

Health category restriction and a doubled container

Medium impact

What is blocking data now

  • Service URLs cover eating disorders, diabetes, IBS and PCOS, so Meta has likely classed the domain as health, which limits lower funnel events
  • GTM-TXPX6DN loads twice, so gtm.js fires twice on every page
  • fbevents.js loads twice from two sources
  • Universal Analytics tags still in the container, collecting nothing

What works after the fix

  • One pixel, one base code, one CompleteRegistration tag
  • Event names and URLs reviewed against the restriction so the signal Meta allows still reaches it
  • Campaign optimisation event set to one Meta will report on
  • A container with only live tags, easier to debug next time
